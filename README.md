# PhishGuard CS-03 — Phishing Awareness Kit

A professional, static GitHub Pages demo for CS-03: Phishing Awareness Kit — Staff Fall for Phishing.

## Included
- Security dashboard
- Safe phishing email simulation
- Suspicious URL heuristic checker
- Micro-learning modules
- Security awareness quiz
- Local audit log and CSV export
- Risk/awareness metrics
- Responsive mobile/desktop UI
- Dark/light theme
- LocalStorage persistence

## Important
This is a safe front-end simulation. It does not send real phishing emails, collect real passwords, perform malware analysis, or provide live URL reputation intelligence. Never use it to collect credentials or target people without explicit authorization.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a repository. Enable GitHub Pages from the repository's Pages settings and select the branch containing these files.
