ANALYSIS

Can you spot the red flags?

01UrgencyPressure to act immediately is a common social-engineering technique.
02Suspicious senderThe sender domain does not match the organization's trusted domain.
03Unexpected verificationUnsolicited login requests should be verified independently.
04Threat of suspensionFear and consequences are used to rush decisions.
💡 Rule: Stop → Inspect → Verify → Report.
Heuristic analysis

Suspicious Link Checker

Analyze a URL for common phishing indicators. This is an awareness tool, not a malware or reputation scanner.

🔐

HTTPS

Encryption helps protect traffic, but HTTPS alone does not prove a website is legitimate.

🌐

Domain

Check the actual registered domain. Look for misspellings, strange subdomains and look-alike names.

⚠

Pressure

Urgent requests for passwords, payments or verification deserve independent confirmation.
